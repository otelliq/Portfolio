# Portfolio

Personal portfolio website built with **Next.js**, **TypeScript**, and **Tailwind CSS**, featuring smooth scrolling and animation.

**Live site:** https://portfolio-kappa-pearl-75.vercel.app

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP (animations)
- Lenis (smooth scrolling)

## Getting started

### Prerequisites

- Node.js (recommended: 18+)
- npm

### Install

```bash
npm install
```

### Run (development)

```bash
npm run dev
```

Open:

- http://localhost:3000

### Build

```bash
npm run build
```

### Start (production)

```bash
npm start
```
